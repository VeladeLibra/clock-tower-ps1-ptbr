# Perguntas frequentes

### O jogo vem junto com a tradução?
Não. O jogo original não é incluído. É necessário ter sua própria cópia legítima de *Clock Tower (USA)*.

### Qual versão é compatível?
A edição americana de PS1 **SLUS-00539**, no formato BIN original não modificado, com 632.629.200 bytes.

### Posso usar o BIN V17 MENU?
Não como entrada no instalador público. O instalador foi preparado para receber o **BIN original**.

### O instalador altera o original?
Não. Ele gera uma **nova cópia traduzida**.

### Preciso baixar o patch separadamente?
Não. Na versão compilada do instalador, o patch fica embutido.

### Como jogar no PC?
Abra o arquivo `.cue` gerado em um emulador compatível. A versão foi testada no DuckStation.

### Há problemas conhecidos?
Ainda podem existir diferenças entre emuladores e configurações. Relate qualquer erro de texto, menu ou instalação na aba **Issues**.
