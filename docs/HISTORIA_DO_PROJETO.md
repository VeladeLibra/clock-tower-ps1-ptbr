# A história do projeto

Sou fã da franquia **Clock Tower há mais de 20 anos**.

Por muito tempo, tive o desejo de traduzir esse jogo para o português brasileiro. Meu objetivo sempre foi **entender toda a história**, compreender os diálogos e os acontecimentos e, assim, aproveitar melhor um jogo que considero ótimo.

Criar esta tradução é realizar um desejo antigo e também compartilhar com outros jogadores brasileiros uma experiência que marcou minha vida com os videogames.

O projeto cresceu com revisões de diálogos, menus, abertura e finais, até chegar à versão V18, com as correções de apresentação do menu e um instalador pensado para ser simples de usar.

Esta é uma tradução de fã, feita por dedicação à franquia e ao seu legado.
