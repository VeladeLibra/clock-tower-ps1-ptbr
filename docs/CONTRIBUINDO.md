# Como contribuir

Obrigado pelo interesse em melhorar **Clock Tower PT-BR**, projeto de fã de **VeladeLibra**.

Para relatar um problema, abra uma **Issue** descrevendo:
1. Qual versão da tradução você utilizou;
2. Em qual tela ou cena ocorreu o problema;
3. O comportamento esperado e o observado;
4. Passos para reproduzir, quando possível.

Você também pode sugerir correções de português e melhorias de clareza.

**Não anexe** arquivos `.bin`, `.iso`, BIOS nem outros conteúdos comerciais do jogo. Evite divulgar dados pessoais em relatórios públicos.

As sugestões serão avaliadas antes de entrar numa versão futura.
